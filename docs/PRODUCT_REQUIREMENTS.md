# Director Master 产品需求

## 目标

把 MiniMax H3 Director 的“素材引用 + 多段时间线 + 生成监控”封装成导演可审核、Agent 可调用的本地工具。用户只写镜头内容，工具负责把已勾选素材映射为每段独立的 Picture/Audio 索引和素材定义。

## 核心流程

1. 从本地项目或上传区建立人物、道具、场景、声音、视频素材库，每个素材保存可复用描述。
2. 在时间线画布添加“素材节点”和“通用提示词节点”：素材节点提供 9 个图片槽位和 3 个音频槽位，通用节点保存项目风格、声音/BGM、字幕/UI 与公共负面约束。
3. 只有素材节点需要连线：像 ComfyUI 一样从素材输出端拖到 SEG 左侧素材输入端；一个素材节点可复用到多个 SEG，每个 SEG 只保留一条素材输入连线。通用提示词节点和剧本节点属于全局作用域，无需连接 SEG。
4. SEG 只填写该段独有的镜头、动作、运镜和对白。提交前自动按“素材引用提示词 + 项目通用提示词 + 分镜提示词”组合六段式 H3 最终提示词。
5. 审核面板同时展示该段素材清单、准确索引、自动素材定义、六段式 H3 最终提示词、负面约束和连续性告警。
6. 自动发现当前已运行的 ComfyUI 监听端口，经本地桥上传素材、提交 API 工作流、轮询队列/历史并展示进度、输出和报错；禁止启动新的 ComfyUI。
7. CLI 接收项目 JSON，让 Agent 可以索引素材、准备工作流、提交任务和查询状态。

## 页面

- 时间轴：核心操作，无限网格画布、节点添加工具栏、素材/通用/分段卡、可选择删除的曲线连线、底部固定成片轨道和右侧审核器。
- 素材库：分类、数量、描述编辑、当前段勾选和自动索引预览。
- 任务中心：ComfyUI 连接、队列、当前阶段、错误、输出。
- 设置：模板路径、项目根目录、模型参数、精修参数。

## 验收标准

- 任意片段都能单独看清镜头提示、素材缩略图、数量、引用索引和生成状态。
- 素材槽位从左到右、从上到下固定映射 Picture 1–9，音频固定映射 Audio 1–3；禁止带空洞的槽位进入生成，避免引用索引错位。
- 修改上游素材节点后，所有已连接 SEG 的最终提示词自动刷新；修改任意通用提示词节点后，全部 SEG 自动刷新，用户无需在分镜提示词中手写 `@素材`。
- 素材连线可点击选中并高亮，按 Delete/Backspace 删除；剧本、通用提示词和成片不产生画布连线。
- 成片按 SEG 顺序显示在画布下方固定轨道，像火车车厢一样连续排列，未生成片段显示等待车厢。
- 多段工作流的 start、length、frameCount、totalFrames 一致，无重叠越界。
- 当前 ComfyUI 未运行时只提示错误；运行时复用实际端口，不创建进程。
- 真实提交一次红绳测试段并拿到成功输出，或完整呈现可定位的 ComfyUI 节点错误。
