# 导演台双通道同步规范

导演台提交时，素材与提示词分成两条独立链路，避免编辑素材描述后仍引用旧编号。

## 1. 素材同步

- 素材节点的图片槽位按 P1→P9、音频槽位按 A1→A3 读取。
- 槽位顺序就是导演台 `refs` / `refAudios` 的顺序；素材交换位置会同步改变数组顺序。
- 每次提交都会重新读取当前素材卡片的 `description`，生成新的 `<Picture N>` / `<Audio N>` 描述。
- 同名文件会被分配稳定的上传别名，避免 ComfyUI 输入目录互相覆盖。

## 2. 引用提示词同步

- `referencePrompt`（兼容旧字段 `definitions`）只保存素材引用说明和编号绑定。
- `commonPrompt` 保存全局风格、声音和禁用规则。
- `shotPrompt` 保存当前 SEG 的镜头动作与台词。
- `prompt` 仍保留完整 H3 提示词，保证现有导演台节点兼容；同时在 `timeline.segments` 写入上述独立字段，便于审阅和后续工具读取。

## 3. 提交前校验

校验会同时检查：

1. 完整提示词和独立引用提示词中的 Picture/Audio 编号是否连续；
2. 编号数量是否与当前素材槽位一致；
3. `refs`、`refAudios` 的文件名、索引和槽位是否逐项一致；
4. timeline 与批处理工作区是否一致。

任一项不一致都会阻止提交并显示具体 SEG、素材类型和编号问题。
