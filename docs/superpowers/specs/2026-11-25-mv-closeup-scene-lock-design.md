# 2026-11-25 MV 特写场景锁定（近脸段也保住场地与光线）

## 背景

2026-11-24 像素幻想口型试片已注入场景锁定词，中景约 4–6 秒明确是白天海边并可见木吉他，但约 0–3 秒与 7–10 秒的紧近脸又掉回偏暗的室内舞台灯。现有 `sceneLockText` 禁止「另造室内灰幕舞台」，却没有点名：**面部大特写时背景仍须是同一场景**。民谣 v2 的面部特写镜头只写锁机位与口型，没有要求背景留下场地、光线与道具残影，模型容易把特写背景发明成棚拍或舞台灯。

本夜收紧特写场景锁定，不新开曲风，不改切镜句界。

## 目标

有场景参考时，场景锁定词必须包含特写约束；民谣独唱/双人唱词段的面部特写与半身弹唱镜头也写明背景仍是参考场景。让口型特写不再默认掉进室内暗背景。

## 行为

1. `buildSceneLockText` / `pack.sceneLockText`：有场景参考时，在既有地点/光线/道具锁定与吉他-麦克风禁令之外，追加中英双语特写条款：即使是面部大特写（tight facial close-up），背景仍须保留场景参考 Picture N 中的同一地点、光线与道具（可虚化 / soft-focus remnants）；禁止改成室内灰幕舞台、舞台灯光、棚拍黑底或凭空夜店灯。无场景参考时仍为空字符串，不发明特写条款。
2. `appendIdentityLockToPrompt` 仍插入完整 `sceneLockText`（含特写条款），幂等行为不变。
3. 民谣独唱/双人模板升至 `folk-solo-ref2va-v3` / `folk-duo-ref2va-v3`：唱词段的面部特写与半身弹唱镜头（camera 行与 shot 正文）须写明参考场景留在背景中（同一地点与光线，禁止室内灰幕/舞台灯/黑底）。无人声远景或琴弦镜头不添加「面部特写也要留背景」这句，以免和「不对脸」冲突。
4. 库约束：`lib/mv-character-consistency.mjs` 与 `lib/mv-prompt.mjs` 不为此引入 `node:`。不改钢琴/摇滚/电音/说唱模板（可下一晚再补同等规则）。

## 非目标

- 不强制取消面部特写（用户仍要求有歌词时多用近脸对口型）。
- 不改迅风自动版（无 prompt 节点）的提交字段。
- 不把 11-24 计费观测写入本规格的阻塞项（可另做）。
- 不在积分不足时自动提交完整云端 MV。

## 验收
