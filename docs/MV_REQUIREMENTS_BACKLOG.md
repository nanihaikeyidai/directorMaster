# MV 工作台需求挖掘与迭代路线

这份清单以“每段提示词可审核、音画同步、批量生产可恢复”为优先级，作为后续实现顺序。当前版本先保证输入变化不会复用旧提示词。

## P0：生产正确性

1. **提示词变更追踪**：切点、歌词、分镜导演词、素材描述、全局规则或模板变化后，段落进入“待重新生成”状态，并显示变化来源。
2. **分段审核状态**：支持“待审核 / 已审核 / 已提交 / 生成失败”状态；批量生成默认只提交已审核段，避免误用旧稿。
3. **生成任务可恢复**：每段保留任务 ID、开始/结束时间、重试次数和错误摘要；支持取消单段、失败重试、断点续跑。
4. **音画对齐检查**：导出前检查每段音频时长、视频时长、首段静音和尾部截断，给出可操作的对齐建议。
5. **最终合成校验**：使用原始音乐作为唯一音轨，检查视频段顺序、空洞、重复和总时长，生成合成前报告。

## P1：效率与可控性

1. **歌词导入**：支持 LRC/SRT/TXT，按时间码预填每段歌词，用户可在波形上微调。
2. **智能切点增强**：结合静音、能量、节拍和歌词结束点给出候选切点；候选点可逐个接受/忽略，始终允许手动覆盖。
3. **素材使用地图**：显示每个 Picture 在哪些段落被引用；删除或移动素材前给出影响范围，并提供锁定槽位避免编号漂移。
4. **段落模板与批量编辑**：对多个段落批量设置镜头风格、景别、运镜、表演强度，同时保留每段差异。
5. **任务队列体验**：展示本地/云端队列、预计等待、并发策略和网络重试；云端串行任务支持暂停后继续。
6. **CLI 对齐**：增加 `validate`、`prompt`、`generate --provider local|runninghub`、`resume`、`manifest` 子命令，与页面使用同一 JSON 交接格式。

## P2：质量与规模化

1. **连续性账本**：记录段尾/段首人物站位、服装、乐器、灯光和镜头方向，生成下一段提示词时自动带入连续性约束。
2. **多版本管理**：保存提示词、切点和素材顺序的快照，可比较差异并回滚到任一版本。
3. **声音与母带处理**：响度归一化、削波检测、淡入淡出和人声/伴奏分离后的可选混音策略。
4. **批量质量报告**：生成后自动检查分辨率、帧率、编码、黑帧、静帧、无声和文件完整性，并汇总为可下载报告。
5. **项目协作与归档**：项目级素材权限、只读审核链接、导出包校验和可重建 manifest。

## 建议下一迭代

优先实现 P0-2（分段审核状态）和 P0-3（可恢复任务），再做 P1-1（歌词导入）。这三项能直接降低“提示词看起来正确但生成错段”以及批量失败后重复劳动的风险。
