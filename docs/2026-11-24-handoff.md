## 1. 项目是什么

- 产品名 **MV Master**，仓库与 CLI 仍叫 `directorMaster` / `director-master`。仓库：https://github.com/nanihaikeyidai/directorMaster

### 切点门禁（`lib/mv-cut-gate.mjs`）

- `parseLyricCues`、`checkMvCuts`、`planMvCutGate`。默认容差 `CUT_GATE_TOLERANCE_SEC = 0.12`。
- 切点只能落在歌词句尾、呼吸或人声空白；禁止固定秒数硬切、禁止句中切。
- 无歌词且无能量 hops → `NO_EVIDENCE` 阻断。`mv-cut` 在 ffmpeg 导出前调用；无 `--lyrics` / `--hops-json` 时会 `probeEnergyHops`，探测失败不得静默跳过。
- CLI：`mv-cut-check`；可选 `--snap-cuts` 吸附到句界后再复检。MV 页 `planMvCutPrecheck` 同样硬拦。

### 歌词语句分段（`lib/mv-lyric-segments.mjs`）

- `planLyricPhraseSegments({ lyrics, durationSec })`：相邻短间隙唱词打包进同一段，单段 ≤ 15 秒，不在句中切开；≥ 2 秒无人声空档单独做远景段。
- 唱词笔记：`shotType=lead`，`coverage=singing-closeup`；无人声：`shotType=wide`，`coverage=instrumental-wide`。可带 `phraseEndsSec` 供 folk v2 按句界切镜。
- CLI：省略 `--cuts` 且提供 `--lyrics` 时走自动分段。页面：`lib/mv-lyric-import-ui.mjs` 的「导入歌词并按语句分段」；非法 JSON 或规划失败只提示、不改已有切点。有 trim 时切点写成绝对时间。单句超过 15 秒会拒绝，需先把时间轴拆短。

### 人物一致性 / 场景锁定（`lib/mv-character-consistency.mjs`）

- `buildCharacterConsistencyPack`、`applyCharacterPackToAssets`、`appendIdentityLockToPrompt(prompt, identityLockText, sceneLockText)`。
- `classifyCharacterRef`：文件名含 `beach` / `海边` / `海滩` 时分为 scene；`newface-beach` 的 B 仍是近脸。
- 近脸若带 `sourcePath` / `croppedFrom`（从原图裁出），会自动把原图挂回为 scene。
- `sceneLockText` 会点名 `Picture N`，禁止改成室内灰幕舞台，也禁止在参考里没有麦克风时把手里的吉他换成麦克风。
- 裁切近脸但没有场景参考时告警。锁词插在 `overall_soundscape` 之前。`mv-cut` 与 MV 页 `buildPackedPrompt` 都走这一套。
- 浏览器侧不要引入 `node:`；扫目录的 FS 逻辑在 `lib/mv-character-consistency-fs.mjs`。

## 4. MV 硬规则（用户长期要求）

1. **口型必须对原曲**；生成后用 ffmpeg **封装原曲音轨**，不用模型生成的替代音乐。`planLipsyncFinalize` / `mv-lipsync-finalize` / 合成门禁都会查这一点。
2. **切点只落在句尾 / 呼吸 / 人声空白**，禁止按固定秒数硬切，禁止在一句歌词中间切开。
3. **正在唱的时候镜头完全固定**（禁止推拉摇移、变焦、手持晃动），只允许表演者动。目前只有 folk-solo / folk-duo v2 强制写进模板。
4. **有歌词**：多用脸部近景和半身弹唱特写搭配，保证口型可读；唱词期间不用场地远景。
5. **无人声**（前奏、间奏、句间长空档）：只用场地远景或琴弦/演奏镜头，不对歌手脸。
6. **换装时人脸必须一致**；走人物一致性包和锁脸词，不要按上传顺序随便取图。
7. **提示词必须走模板管线**（`buildMvPromptForTemplate` / 页面打包后再注入锁脸锁场景词）。
8. **口型试片只用人声段**：活跃比 ≥ 0.35（`DEFAULT_MIN_VOCAL_ACTIVE_RATIO`）；参考图必须是近脸。间奏/纯器乐段过不了 prep 门禁，不要花钱。
9. **不要把密钥、成片、源音乐、任务回执提交进 Git**。可提交的只有应用代码、文档和 `workspace/workflows/` 下的可复用模板。

每段生成硬限制 15 秒。H3 提示词六段式：`subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`。`<Picture N>` 必须和 `refs[index=N-1]` 对上。
