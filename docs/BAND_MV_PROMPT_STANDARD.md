# Director Master 乐队 MV 提示词标准

模板版本：`band-live-ref2va-v4-duration-shot-grammar`

## 目标

把用户上传的人物、乐器、服装、站位、场景和音轨描述稳定转换为 MiniMax H3 Ref2VA 六段式提示词。网页 MV 页面与 `director-master mv-cut` CLI 共用 `lib/mv-prompt.mjs`，避免本地与云端生成使用不同的提示词结构。

## 输入约定

- 视觉素材总数不超过 MiniMax H3 的 9 张限制。
- 素材数组顺序严格对应 `<Picture 1> ... <Picture N>`。
- 每张图片同时生成一个同编号 `<Subject N>`，方便工作流引用校验。
- 第一张人物素材默认是视觉主角。需要改变主角时，在该分段的导演说明中明确指定。
- 人物描述应写清：姓名或稳定称呼、成年身份、外貌、发型、服装、乐器、舞台站位。多人设定图必须逐人描述，不能只写“乐队成员”。
- 场景描述应写清：舞台结构、前后左右空间、灯光色彩、地面与背景、观众位置、关键视觉锚点。
- `<Audio 1>` 永远表示当前导出的音乐分段，也是表演、口型、剪辑和灯光节奏的权威时间参考。
- `<Audio 1>` 同时是演唱启停的唯一信号。前置静音、纯音乐和人声停顿期间所有人物保持自然闭口；人声出现时才允许按音节驱动嘴型、下颌、呼吸和句尾收口。
- `leadSilenceSec + settings.vocalStartSec` 决定整条编辑音轨上的首次人声时间；模板会换算成片段内时间并写入提示词。SEG 01 额外固定为无演唱前奏，用准备动作承接后续片段。

素材描述示例：

```json
{
  "主唱.png": "Camilla，成年女主唱，银白长发、浅灰眼睛，银黑色金属演出服，手持黑色麦克风，位于舞台前方中央。",
  "乐队成员.png": "Luna 是粉色高马尾鼓手，位于后方中央；Seraphine 是黑色长发吉他手，位于画面左侧；Naya 是蓝色短发贝斯手，位于画面右侧。三人均为成年女性，穿黑银色摇滚演出服。",
  "舞台.png": "大型室内演唱会舞台，冷蓝白聚光灯、LED 大屏和桁架灯光，反光地面与中央台阶，观众位于舞台前方并挥动荧光棒。"
}
```

## 固定输出结构

提示词始终按以下顺序输出：

1. `subject_definitions`
2. `summary`
3. `retention_analysis`
4. `detailed_description`
5. `overall_soundscape`
6. `non_diegetic_music`

`detailed_description` 根据当前分段时长动态分配镜头：

- 少于 4 秒：一个连续可读镜头，不强行切镜。
- 4–8 秒：两个镜头，在第一个动作或乐句后切换。
- 8–12 秒：三个镜头，按乐句/节拍分配两个切点。
- 12–15 秒：四个镜头，按乐句/节拍分配三个切点，依次覆盖主唱建立、其他乐手特写、观众/后场空间关系和主唱情绪收束；素材不足时退化为全乐队与主唱的不同机位，不虚构新人物。
- 每个分段根据 SEG 序号轮换广角、侧面、俯拍、后场、长焦和环绕等镜头语法；相邻镜头至少改变主体焦点、景别、镜头焦段、机位高度、屏幕方向或运动方向中的两项，避免连续镜头只做小幅裁切。

切点按分段自身时长动态计算，不使用整首音乐的绝对时间。切点、音频时长、素材描述或全局规则变化后，必须重新生成标准提示词。

## 固定质量约束

- 真人写实、真实成年演员、自然皮肤和头发、可信服装与乐器材质。
- 人物身份、面孔、服装、乐器、站位和舞台轴线保持一致。
- 禁止人物复制、换脸、乐器互换、畸形手、无关舞蹈、额外乐手。
- 禁止参考图背景纸、标签、签名、字幕、歌词文字、Logo、水印和其他可读文字。
- 原始分段音轨在后期重新封装为最终音轨；移除 AI 生成音轨，不改速、不变调、不重混。
- 禁止无声时提前张嘴、纯音乐假唱、停唱后继续动嘴，以及用镜头时间代替音频信号判断演唱状态。

## CLI

```powershell
npm run director -- mv-cut `
  --audio "D:\music\song.wav" `
  --project "乐队MV" `
  --cuts "12.8,25.1" `
  --notes "D:\music\segments.json" `
  --people "D:\music\people" `
  --scenes "D:\music\scenes" `
  --asset-meta "D:\music\asset-descriptions.json"
```

`--asset-meta` 接受以上述文件名或不带扩展名的素材名为键的 JSON 对象，也接受包含 `fileName`/`name` 与 `description` 的数组。

## 一致性要求

- 网页点击“生成标准提示词”和 CLI `mv-cut` 必须调用同一个模板函数。
- 本地导演台与 RunningHub 提交必须使用已审核的 `generatedPrompts[index]`，禁止云端工作流保留其自带示例提示词。
- 素材、顺序、描述、切点或全局导演规则变化后，旧提示词自动失效，必须重新生成并审核。
