# EP03 历史工具

这里保存 2026 年 9 月为《红绳》EP03 做一次性批处理和验片时使用的 Python 脚本。它们保留了当时的命令、路径和验证方法，便于追溯旧产物，但不属于当前产品代码，也不在默认测试中执行。

注意事项：

- 脚本包含旧机器上的绝对路径，不能假定换机器后仍可直接运行。
- 部分脚本会向本地 ComfyUI 提交任务或读取旧生产目录；运行前先核对目标文件和当前工作流。
- 当前产品入口优先使用 `npm run director`、`/api/local/*` 和 `lib/` 下的领域模块。
- 不要把这些脚本里的样例提示词、剧情或素材当成新项目的永久模板。
